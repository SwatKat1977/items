{# Deleting a section is ONE confirmation that says what will be lost. Each section's delete button carries how many test cases deleting it removes (data-testcase-count: the section and every sub-section, worked out from the list already on the page). project_testcases.js fills the pop-up in from the button that opened it: - no test cases: a plain confirmation, posting a plain delete; - some: a red warning with the count, a confirmation worded to match, and a button that posts cascade=true. The count can only be stale if someone adds a test case after the page loaded. For that case the CMS still refuses a plain delete, and the page comes back with the backstop prompt below, which explains itself and is opened automatically (data-auto-open). #}
